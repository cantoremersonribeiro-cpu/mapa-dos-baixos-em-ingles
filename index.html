QUESTIONS

Before you buy

Does it work for a 48 or 80-bass accordion?

Yes. The guide is drawn on the 120-bass, which has six rows. The 80-bass has five — no diminished row — and the material flags that every time it comes up. Smaller instruments follow the same Stradella logic with fewer buttons.

I cannot read music. Can I still follow it?

You can. There is not a single staff in the material. It is all button diagrams, note names and finger numbers.

I am a complete beginner. Is this too advanced?

It is built to start from zero. The first lesson teaches you how to find the C button, which is where everything else begins.

I am over 60 and my close vision is not what it was.

The PDF is set in large type on a cream background with no light grey text, following the standard legibility guidance for readers over 60. You can also print it or zoom in on your phone.

Piano accordion or button accordion?

The right hand shown is a piano keyboard. But the bass system taught here is Stradella, which is the same on nearly every piano and chromatic button accordion. It does not apply to the diatonic button box used in Cajun, zydeco, Tex-Mex or Irish traditional playing.
